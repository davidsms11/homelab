# Hardware

## Overview

This Home Lab runs on a dedicated HP EliteDesk 800 G3.

The server provides a reliable and energy-efficient platform for virtualization and self-hosted services. It is used to host the complete Home Lab environment and serves as the foundation for all virtual machines and containers.

---

## Specifications

| Component      | Details             |
| -------------- | ------------------- |
| Server         | HP EliteDesk 800 G3 |
| CPU            | Intel Core i5-6600  |
| Memory         | 16 GB DDR4          |
| Planned Memory | 32 GB DDR4          |
| System Drive   | 256 GB NVMe SSD     |
| Data Drive     | 1.5 TB HDD          |

---

## Purpose

The hardware was selected because it provides:

* Low power consumption
* Reliable business-class hardware
* Good performance for virtualization
* Easy future upgrades
* Excellent value for a Home Lab
